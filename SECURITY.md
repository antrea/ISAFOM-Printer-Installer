# Segnalazioni riservate

Per vulnerabilità o problemi che coinvolgono Account ID, password, configurazioni personali o dati dei PC, contattare **Andrea Esposito — andrea.esposito@cnr.it**. Non pubblicare codici, nomi personali, dump, esportazioni del registro o raccolte non esaminate nelle issue.

Per errori ordinari indicare versione del tool e di Windows, versione del driver, fase e codice dell'errore. Usare dati sintetici per gli esempi. L'installer modifica componenti di stampa con privilegi amministrativi; i test normali non autorizzano test distruttivi sull'ambiente operativo.
